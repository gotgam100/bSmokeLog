B Smoke Log is built on Apple's own frameworks and has no third-party open-source package dependencies.

Apple frameworks used

  • SwiftUI, Swift Charts — interface and charts
  • SwiftData, CloudKit — storage and iCloud sync
  • WidgetKit, App Intents — widgets, Control Center, Shortcuts
  • UserNotifications — weekly summary notification

Included items

  • Third-party open-source packages: none

The app's source code is available on GitHub.
